## 검증 범위의 한계

- 검증용 브라우저는 `file://` 탐색을 보안 정책으로 차단했습니다. 따라서 직접 파일 실행은 코드에 지원되지만 실제 브라우저에서 검증하지 않았습니다. HTTP 서버 방식은 실제 실행을 검증했습니다.
- 다른 브라우저, 실제 휴대전화·터치 및 별도 모바일 화면 크기에서는 검증하지 않았습니다. 반응형 CSS와 Pointer Events는 구현되어 있습니다.
- 실제 마우스 휠의 커서 고정 동작은 별도 수동 검증하지 않았습니다. 동일한 좌표 변환·zoomAt 함수는 자동 테스트를 통과했고, 실제 화면의 확대·축소 버튼도 확인했습니다.
- Node 대체 서버는 문법 검사만 수행했습니다. 실제 HTTP 실행 검증에는 Python 서버를 사용했습니다.
- 극단적인 전하량 비율 및 근접 전하 테스트는 유한성·적분 종료·샘플 유지 확인입니다. 모든 극한 배치에 대한 정량적 오차 보장은 아닙니다.
