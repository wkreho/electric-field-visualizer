## 자동 검증

```powershell
node --test tests/physics.test.cjs tests/metadata.test.cjs tests/simulation.test.cjs
```

**53개 통과, 실패 0. 기존 23개 + 동적 모델 30개입니다.** 최종 재실행은 약 0.50초(앞선 실행 약 1.27초)였습니다. JS 문법 검사도 통과했습니다.

요청된 13개 물리 검증을 모두 실제 수행했습니다: Fixed 위치 유지, 같은 부호 반발, 반대 부호 인력, 부호 반전 시 힘 반전, q=0 무전기력, 질량 2배 시 가속도 절반, 링 중심 E≈0, 원판 중심 E≈0, 샘플 총전하량 Q 보존, 모두 Fixed이면 무운동, 초기 위치·속도 복원, 카메라 조작의 물리 좌표 불변, Δt 감소에 따른 에너지 오차 감소.

추가 검증:

- 원판의 동일 면적 고리 셀은 샘플 수가 같으며, 가중 평균 r²는 R²/2.
- 독립된 Free Point / Ring / Disk는 자기 장 때문에 가속하지 않음.
- Free Ring–Free Disk의 힘은 퍼텐셜의 수치 기울기와 일치하고 작용·반작용이 정확히 반대.
- Free Ring / Disk가 실제 병진하며 반지름 유지.
- 두 Free 점전하의 운동량·질량중심 보존.
- 초기 횡방향 속도 유지: 운동 궤적을 전기력선에 제한하지 않음.
- 같은 고정 스텝 수에서 Speed 0.1× / 8×가 같은 물리 상태 생성.
- 링의 빈 내부는 허용하고 전하 물질의 접촉은 거부.
- 큰 이동량·관통 위험·잘못된 Δt는 상태를 변경하기 전에 정지.
- 잘못된 질량·반경·NaN·Infinity·이름·ID·과도한 샘플 계산량 거부.
- 여섯 프리셋이 기본 Δt에서 각각 500스텝(1초) 안전하게 진행.
- 궤적의 길이 제한과 Clear Trails의 물리 시간·속도 불변.
- JSON 현재 상태·초기 상태·ID·이름·카메라·설정 왕복.
- 음전하만 있는 동적 Field도 안쪽 화살표·유한한 선 생성.
- 기존 정적 5개 프리셋의 수정 전 계산점 회귀 비교 통과.

### 에너지 수렴

고정 점전하 + 편심 궤도 시험전하를 2초 계산한 최대 `|E−E₀|/(K₀+|U₀|)`:

| Δt | 정규화 오차 | 퍼센트 |
|---:|---:|---:|
| 0.008 | 0.0005662198 | 0.056622% |
| 0.004 | 0.0001419892 | 0.014199% |
| 0.002 | 0.00003551235 | 0.003551% |

Δt를 절반으로 줄일 때 최대 오차가 약 1/4로 감소했습니다.

### 분포 전기장 근사

- 링의 평면 내 중심 부근에서 `Ex ≈ −kQx/(2R³)`의 복원력 기울기 확인.
- 링·원판의 원거리 장이 점전하 극한 `kQ/r²`로 접근함을 확인.
- 원판 Q=1e-8 C, R=1m, 평면 내 (1.7,0)m의 별도 32,768샘플 기준값 Ex=36.3113210 N/C.
- 해당 지점의 상대 오차: 낮음 0.285508%, 기본 0.071034%, 높음 0.017741%. 모든 위치의 오차 보장은 아니며, 경계·원판 내부는 별도 한계가 있습니다.

## 수정 중 발견·해결한 사항

- 작은 화면에서 네비게이션 높이 규칙과 세로 레이아웃이 충돌해 Canvas가 위로 밀리는 문제를 수정.
- 일시정지 후 속성을 편집할 때 이전 초기 좌표로 돌아가지 않도록 현재 좌표·속도를 속성 패널에 동기화.
- 물체 추가·삭제 직후 샘플 수가 이전 값으로 남지 않도록 구조 변경 시 갱신.
- Field를 껐을 때 계산 중 문구가 남지 않도록 숨김 상태를 명시.
- JSON 품질 옵션을 정해진 low / medium / high로 제한하고, 객체의 상속 속성 이름도 거부하도록 검증 보강.

## 검증 범위·알려진 한계

- 회전·변형·자기장·복사·상대론·충돌 후 운동은 의도적으로 제외했습니다. Ring / Disk의 Free 병진운동은 힘·에너지·작용반작용 검증 후 활성화했습니다.
- 전하 물질이 겹치는 배치는 허용하지 않습니다. 보수적인 안전 이동량 검사로 실제 접촉보다 일찍 정지할 수 있습니다.
- 분포는 유한 샘플 근사입니다. 근접 경계·원판 내부의 값은 고정 오차를 보장하지 않습니다. 내부 측정에는 근사 표시를 제공합니다.
- 부하가 크면 지정한 배속보다 느려질 수 있습니다. 물리 Δt를 늘려 따라잡거나 임의 힘을 추가하지 않습니다.
- JSON / 페이지 복원에 궤적 히스토리는 포함하지 않습니다.
- 다른 브라우저·실제 터치 장치·원격 GitHub Pages 배포는 직접 검증하지 않았습니다. 런타임 외부 의존성이나 서버 API는 없습니다.
- 요청된 핵심 기능에 미구현 항목은 없습니다. 검증하지 않은 UI 조작 범위는 위에 구분했습니다.
